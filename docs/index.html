03

Por qué colapsa el Tier 3

Gemini y Grok siguieron al pie de la letra la arquitectura multiescala entrenada desde cero. ChatGPT y Claude la sustituyeron por una ResNet18 preentrenada. Un diseño factorial 2×2 aísla la causa.

Con el mismo calendario, la red preentrenada llega a 0.945–0.947 y la red desde cero se queda en 0.53–0.57, cerca del azar. Cambiar el planificador apenas mueve el resultado. El factor decisivo es partir de cero con 478 imágenes.

5 ejecuciones × 20 épocas por celda. Misma partición, aumentos, optimizador y parada temprana. La línea vertical marca 0.5 (azar).

06

Reproducir

Todo lo que muestra esta página sale de archivos del repositorio. Con PyTorch instalado, un comando relanza los experimentos de la revisión y otro regenera los datos de esta web.

# experimentos de revisión (k-fold, línea base, ablación)
pip install -r requirements.txt
nohup bash run_experiments.sh > revision/logs/run_all.log 2>&1 &

# estadística a partir de los registros crudos (sin entrenar)
python revision/stats_analysis.py

# datos de esta web
python docs/build_data.py
