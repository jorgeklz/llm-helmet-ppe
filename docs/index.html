Run it yourself

Everything in this lab is computed from files in the repository. These commands reproduce it from the repository root.

1 · Set up

Python 3.9+ with the pinned dependencies (PyTorch 2.8, torchvision 0.23).

$ git clone https://github.com/jorgeklz/llm-helmet-ppe.git $ cd llm-helmet-ppe $ pip install -r requirements.txt

2 · Run one LLM-generated script

Each script trains, evaluates on the 494 test images and appends its runs to the matching CSV.

3 · Recompute the statistics

No training needed. Rewrites revision/stats_summary.csv and revision/stats_tests.txt in seconds.

$ python revision/stats_analysis.py

4 · Rerun the reviewer experiments

k-fold CV, expert baseline and Tier-3 ablation in the background. Several hours on CPU.

$ mkdir -p revision/logs $ nohup bash run_experiments.sh > revision/logs/run_all.log 2>&1 & $ tail -f revision/logs/run_all.log

5 · Refresh this lab

Regenerates docs/data.js from the logs. A push to main republishes the site.

$ python docs/build_data.py
